# Forest studio

The user selected Forest studio on 14 November 2026. This is the shared design for the full Home training app.

The next workout leads the overview. Its real movement list sits beside the original rotatable human guide. Upcoming sessions follow as a simple row. Recorded work and plan details sit below that main action.

Use a centred, capped layout with a quiet top navigation on desktop and the existing five destinations within reach on phones. Keep setup, scheduling, exercise guides, progress, backups and installation available. Each screen uses the same typography, spacing and controls.

Forest and Ivory in light appearance remains the default. All existing palettes and light, dark and device appearance preferences use this layout. Their semantic colour roles live in src/themes.js. Layout and type tokens live in src/studio.css.

Use the bundled Manrope for headings and the wordmark, and DM Sans for body text and controls. Headings have one colour and weight. Labels use normal case without tracked capitals. Buttons and navigation keep visible keyboard focus and useful touch targets.

Use whitespace and thin rules to group content. Give the movement guide a pale surface with generous rounded corners. Keep forms and recorded data plain and readable. Avoid repeated boxed summaries and decorative status marks.

The overview shows actual planned prescriptions and recorded totals. Selecting an overview movement previews it without changing the session. Starting a workout retains the session review and warm-up guidance. Training rules, local storage keys, backup compatibility and video permissions stay in their existing modules.

The original 3D guides remain simplified illustrations. Professional reference comparisons do not imply trainer approval. Retain that qualification and the existing consent and discomfort guidance.
